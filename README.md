# Перспектива: проверка рисунка

Приложение для проверки нарисованных от руки кубов и коробок в перспективе: находит рёбра, раскладывает их по трём направлениям, проверяет сходимость к точкам схода, правдоподобность камеры и пропорции, показывает ближайший правильный куб.

Всё приложение — один файл `index.html` (собранная версия). Открой его в браузере, сервер не нужен.

Опубликованная версия: https://claude.ai/artifact/GJN7ihKz2djhhnzzB6Ufai
